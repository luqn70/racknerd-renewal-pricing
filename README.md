## 续费同价到底锁住了什么

RackNerd 公开的政策是：所有套餐续费均按购买时的价格计算。活动套餐、常规特价套餐、标准月付套餐都适用这一条。你以 $11.29 买的活动机，第二年账单还是 $11.29；以 $21.99 买的常驻特价，三年都是 $21.99。

锁定的对象是「你这个账户下这个套餐的价格」。不是你的账号，也不是品牌整体，所以下面两个操作会让它失效。

**断档。** 套餐到期没续，系统暂停服务，过一段时间再想激活，可能就按当时现行的价格重新下单了。活动价买的尤其要注意，活动价和现行价能差一倍。这条是续费同价最重要的前提：持续续费、不断档。

**升级。** 配置不够用时可以升到更高一档，升级时按差价补费，这部分没有问题。问题在于升级完成之后，续费价格按新套餐的价格计算，原来那份活动价合同就结束了。如果当前配置还撑得住，为了「升一点」把已经锁定的低价弄丢，通常不划算。

续费本身不复杂，系统默认在到期前两周自动生成续费账单并发到注册邮箱。想提前处理就手动走一遍：

1. 登录客户中心，点开要续费的那台服务，进入详情页
2. 左侧 Actions 栏里点 Generate Renewal Invoice
3. 打开生成的账单，核对金额
4. 完成付款，服务周期顺延一个计费周期

付款支持 PayPal、信用卡、支付宝，国内用户不用折腾外币卡。

## 常见问题

**续费能续几次？**
RackNerd 没有次数上限。每次到期前正常续费，价格一直按首次购买价走。

**中间断了一年，还能按原价恢复吗？**
不保证。服务暂停后再激活，可能按当时的现行价重新下单，活动价尤其如此。

**升级配置后续费怎么算？**
按新套餐的价格算，原来的锁定价不再适用。当前配置够用就别升。

**活动套餐也享受续费同价吗？**
享受。活动套餐、常规特价、标准月付三类都适用同一条政策。
